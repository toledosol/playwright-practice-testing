# Playwright Test Automation Suite

Este repositorio contiene la automatización de pruebas end-to-end (E2E) para el sitio web [Practice Software Testing](https://practicesoftwaretesting.com/).

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** TypeScript / JavaScript
* **Framework:** Playwright
* **Patrón de diseño:** Page Object Model (en construcción)
* **Reportes:** Playwright HTML Reporter

## 🚀 Escenarios automatizados
* **Autenticación (Login):** Validación de inicio de sesión exitoso con credenciales válidas (*Happy Path*).
